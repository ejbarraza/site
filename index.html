The audit work

Information disclosure, not a broken spec. The PDF format keeps text and drawings in separate layers — paint is not removal.

PdfCraft faux-redaction auditor — Rust

The threat model is a recipient who extracts text, not just views the page. A “redaction” that only paints a black box leaves the sensitive text in the file, one copy-paste away. That's incomplete data removal leading to information disclosure.

Question it answers: before you share a PDF, is anything you think you removed still recoverable from the file itself?

covered-text

An opaque rectangle, closed path, or /Square annotation painted after the text it covers — while the text stays extractable underneath.

unapplied-mark

A /Redact annotation placed but never applied, so the underlying text is completely untouched.

  • 1Fail-closed. Undecodable streams, malformed annotations, or form XObjects nested deeper than 32 — or in a cycle — are an error, never a clean “no findings.”
  • 2False-positive discipline. A shape only counts if painted after the text and dark enough to hide it (WCAG contrast < 3.0), so table shading and highlights aren't flagged.
  • 3Permissions respected. If the document withholds copying, findings are still reported — the recovered text is left blank.
